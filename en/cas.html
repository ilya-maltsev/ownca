Create new authority

There is no backend picker: with OWNCA_CRYPTOPRO_ENABLED on, GOST algorithms go to CryptoPro CSP and every other key family stays on openssl. The choice is fixed when the CA is created and never changes; an intermediate inherits its parent's backend.

Import existing authority

Bring an existing CA under management by uploading its certificate and private key, or a single PKCS#12 (.pfx / .p12) container holding both. OwnCA will use it to sign new certificates. Type (root / intermediate) and key algorithm are detected automatically.

PKCS#12 container (.pfx / .p12)

Uploading a PKCS#12 file supplies both the certificate and private key — the separate fields below are then ignored. Files sealed with older ciphers (RC2-40 / 3DES, e.g. Windows exports) are read via OpenSSL's legacy provider automatically.
