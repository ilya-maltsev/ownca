# Пароль администратора

Настроек парольной политики в панели нет: пароль администратора задаётся
переменной окружения.

## Как задать пароль

Укажите `DASHBOARD_ADMIN_PASSWORD=<новый_пароль>` в `dev_env/.env` (или в
переменных окружения контейнера) и перезапустите контейнер — новый пароль
вступит в силу при запуске.

## Надёжность пароля

Пароль из переменной окружения устанавливается без проверок: длина,
сложность и наличие в словаре распространённых паролей **не проверяются**
(иначе не работал бы пароль по умолчанию `admin`). Выбирайте надёжный
пароль самостоятельно.
