# Выгрузка в PKCS#12

Файл PKCS#12 (`.p12`, `.pfx`) содержит сертификат, его закрытый ключ и всю
цепочку сертификатов УЦ и защищён паролем. Его принимают хранилище
сертификатов Windows, браузеры и большинство клиентов VPN и почтовых
программ.

## Когда нужен PKCS#12

* Импорт в хранилище сертификатов Windows (`certmgr`, `certlm`).
* Настройка подписи и шифрования почты (S/MIME) в Thunderbird или Outlook.
* Настройка клиента VPN, которому нужен один файл с ключом.
* Любая программа, которая не принимает сертификат, ключ и цепочку
  отдельными файлами PEM.

## Как выгрузить

На странице сертификата (`/certificates/<uuid>/`) нажмите
**Экспорт PKCS#12**. Под кнопками откроется форма с полем пароля; кнопка
**Скачать .p12** сохранит файл.

Кнопка есть, только если закрытый ключ сертификата хранится на сервере.
У сертификата, выпущенного по внешнему запросу, ключа в OwnCA нет, и
кнопка скрыта.

**Требования к паролю:**

* пароль не может быть пустым;
* не длиннее 32 символов и без переводов строки — более длинный пароль
  сервер отклонит; не короче 4 символов — это проверяет только браузер;
  в остальном следуйте парольной политике своей организации;
* тот же пароль понадобится при импорте файла.

## Содержимое файла

| Элемент | Содержимое |
|---|---|
| `certBag` | Сертификат (отображаемое имя — Common Name). |
| `keyBag` | Закрытый ключ. |
| `certBag` × N | Цепочка УЦ — подчинённые и корневой, найденные по издателю. |

## Формат ТК 26 (только для ГОСТ-ключей)

Если у сертификата ГОСТ-ключ (ГОСТ Р 34.10-2012, 256 или 512 бит), рядом с
полем пароля появляются флажок и выбор шифра:

> [x] **TK-26 формат (RFC 9548)**
> Шифр: [`kuznyechik-ctr-acpkm` ▾]

С этим флажком файл формируется по RFC 9337 и RFC 9548 (рекомендации
ТК 26). Ключ и сертификаты шифруются по схеме PBES2 с PBKDF2-HMAC-Стрибог
и выбранным шифром (Кузнечик или Магма в режиме CTR-ACPKM); общая
контрольная сумма — HMAC-Стрибог-512 с выработкой ключа по RFC 9548,
п. 3 (PBKDF2 с `dkLen=96`, ключом HMAC служат последние 32 байта). Такой
файл принимают CryptoPro CSP и другие криптопровайдеры с поддержкой ТК 26.

Выбранный шифр используется и для ключа, и для сертификатов
(`openssl pkcs12 -keypbe` и `-certpbe`). Доступны `kuznyechik-ctr-acpkm`
(по умолчанию) и `magma-ctr-acpkm`.

Для ГОСТ-сертификата возможны **два** правильных варианта файла —
выбирайте по программе, в которую будете его импортировать:

* программа не поддерживает ТК 26 — снимите флажок; получится обычный
  `.p12` (PBES2, AES-256-CBC, PBKDF2-HMAC-SHA-256);
* криптопровайдер поддерживает ТК 26 — оставьте флажок и при необходимости
  выберите другой шифр; файл `.gost.p12` импортируется без
  преобразований.

Для сертификата с ключом RSA запрос с этим флажком отклоняется: без
ГОСТ-ключа формат ТК 26 не имеет смысла.

Файл формирует стандартная команда `openssl pkcs12 -export` с модулем
gost-engine, поддерживающим RFC 9337 и RFC 9548
([`gost-engine/engine`](https://github.com/gost-engine/engine), поддержка
добавлена в основную ветку в запросе на слияние № 527).

## Выгрузка УЦ

В PKCS#12 можно выгрузить и **сертификат с ключом самого УЦ**. На странице
УЦ (`/cas/<uuid>/`) нажмите **Экспорт PKCS#12** и выберите шифрование:

| Шифрование | Шифр / контрольная сумма |
|---|---|
| Стандартный (AES-256, совместимый) | AES-256-CBC, SHA-256 — подходит для большинства программ. |
| ГОСТ Кузнечик — ТК-26 (RFC 9548) | `kuznyechik-ctr-acpkm` / `md_gost12_512`. |
| ГОСТ Магма — ТК-26 (RFC 9548) | `magma-ctr-acpkm-omac` / `md_gost12_256`. |
| ГОСТ 28147-89 (устаревший) | `gost89` / `md_gost94` — для программ без поддержки ТК 26. |

Для подчинённого или импортированного УЦ можно также отметить
**Включить цепочку**, чтобы добавить в файл сертификаты родительских УЦ.
См. [Управление УЦ](cas.md).

## Примеры импорта

**Windows:**
```
certutil -importpfx -p "пароль" cert.p12
```

**macOS:**
```
security import cert.p12 -P пароль -k login.keychain
```

**Linux (NSS):**
```
pk12util -i cert.p12 -d sql:$HOME/.pki/nssdb -W пароль
```

**CryptoPro CSP в Windows (`.gost.p12`):**

```
csptest -keyset -container "\\.\HDIMAGE\<имя-контейнера>" \
        -keytype exchange -import cert.gost.p12 -pwd "пароль"
```

Или через графический интерфейс: *КриптоПро → Сервис → Установить личный
сертификат*, затем укажите файл `.gost.p12`.

> **УЦ на CryptoPro CSP.** Для сертификатов такого УЦ файл PKCS#12
> формирует сам CryptoPro, поэтому формат ТК 26 (`.gost.p12`) и
> ГОСТ-шифрование недоступны, а закрытый ключ нельзя выгрузить в PEM.
> Подробнее — в разделе [Криптопровайдер CryptoPro CSP](cryptopro.md).
