# Устройство сертификата X.509

Сертификат X.509 версии 3 — подписанный документ, который связывает
открытый ключ с его владельцем.

## Основные поля

| Поле | Описание |
|---|---|
| Версия | OwnCA выпускает только сертификаты версии 3. |
| Серийный номер | Положительное целое число, уникальное в пределах УЦ. |
| Issuer / Subject | Отличительные имена (DN) УЦ и владельца (CN, O, OU, C, ST, L и др.). |
| Срок действия | Начало (`notBefore`) и окончание (`notAfter`). |
| Открытый ключ | Алгоритм и сам ключ. |
| Расширения | Дополнительные поля (Key Usage, SAN, точки распространения и др.); есть только в версии 3. |

## Расширения

Каждое расширение содержит OID, признак критичности (`critical`) и
значение. Если расширение помечено как критическое, проверяющая сторона
**обязана** его понимать, иначе она должна отвергнуть сертификат.

### Основные расширения

| OID | Название |
|---|---|
| `2.5.29.14` | Subject Key Identifier |
| `2.5.29.35` | Authority Key Identifier |
| `2.5.29.15` | Key Usage |
| `2.5.29.32` | Certificate Policies |
| `2.5.29.17` | Subject Alternative Name |
| `2.5.29.19` | Basic Constraints |
| `2.5.29.30` | Name Constraints |
| `2.5.29.36` | Policy Constraints |
| `2.5.29.37` | Extended Key Usage — см. [Key Usage](key_usage.md) |
| `2.5.29.31` | CRL Distribution Points — см. [Точки распространения](distribution_points.md) |
| `1.3.6.1.5.5.7.1.1` | Authority Information Access |
| `1.3.6.1.5.5.7.1.11` | Subject Information Access |

## Подпись

Сертификат подписывается закрытым ключом выпускающего УЦ. Алгоритм
подписи зависит от ключа УЦ: RSA, ECDSA, Ed25519 или ГОСТ (см.
[ГОСТ-алгоритмы](gost_algorithms.md)).
