# Конфигурация

Страница `/system/configuration/` (пункт меню **Конфигурация**) состоит из
двух частей:

* **Режимы выпуска** — переключатели, которые определяют, какие семейства
  ключей, способы создания ключа, форматы выгрузки и правила профилей
  разрешены. Они хранятся в базе данных и сохраняются кнопкой
  **Сохранить настройки**.
* **Значения по умолчанию** и **Переменные окружения** — только для
  просмотра: показывают значения, прочитанные из переменных окружения при
  запуске, чтобы их можно было проверить, не заходя в контейнер.

## Режимы выпуска

Переключатели действуют везде, где возможно соответствующее действие:
интерфейс скрывает запрещённые варианты, **а** сервер отклоняет запросы, в
которых их пытаются передать в обход интерфейса. Ниже указаны значения при
первом запуске; изменить их можно в любой момент.

| Переключатель | По умолчанию | Что происходит, если он **выключен** |
|---|---|---|
| **Разрешить генерацию ключей на сервере** | вкл | Панель не создаёт закрытые ключи: в форме выпуска принимается только загруженный запрос (CSR). См. [Выпуск сертификата](custom_cert_issue.md). |
| **Разрешить ГОСТ-ключи** | вкл | ГОСТ Р 34.10-2012 (256 / 512 бит) убирается из списков алгоритмов для новых УЦ и сертификатов. Кроме того, для ГОСТ нужен загруженный gost-engine — его состояние видно на странице [Обслуживание](maintenance.md). См. [ГОСТ-алгоритмы](gost_algorithms.md). |
| **Разрешить RSA-ключи** | вкл | RSA (2048 / 4096) убирается из списков алгоритмов. |
| **Разрешить ECDSA / Ed25519** | **выкл** | Если включён, предлагаются ECDSA (P-256, P-384) и Ed25519. По умолчанию выключен, поэтому эти алгоритмы сначала недоступны ни для УЦ, ни для сертификатов. |
| **Предлагать экспорт .gost.p12** | вкл | Выгрузка в формате ТК 26 `.gost.p12` (RFC 9337, RFC 9548) скрыта на странице сертификата и отклоняется сервером. Для ключей не ГОСТ переключатель ни на что не влияет. См. [Экспорт PKCS#12](pkcs12_export.md). |
| **Разрешить выпуск без профиля** | **выкл** | Профиль в форме выпуска **обязателен**: варианта «Свободный (без профиля)» нет, а сервер отклоняет запросы без профиля. Если переключатель **включён**, можно выпускать сертификаты без профиля и тем самым обходить ограничения профилей (KU, EKU, расширения, OID). См. [Выпуск сертификата](custom_cert_issue.md). |

> **Где действуют переключатели семейств ключей.** Переключатели ГОСТ, RSA и
> ECDSA действуют **и** при создании УЦ, **и** при выпуске сертификатов:
> списки алгоритмов содержат только разрешённые семейства, а сервер
> отклоняет запрещённое семейство, даже если его передать в запросе
> вручную. На **продление** они не влияют: при продлении используется
> прежний ключ, поэтому сертификат, выпущенный до запрета семейства, можно
> продлить.

## Значения по умолчанию

Только для просмотра: значения, прочитанные из переменных окружения.

| Поле | Переменная окружения | Назначение |
|---|---|---|
| Каталог хранения | `OWNCA_STORAGE_DIR` | Каталог, где хранятся ключи и сертификаты. По умолчанию `/var/lib/ownca`. |
| Алгоритм ключей по умолчанию | `OWNCA_DEFAULT_KEY_ALG` | Алгоритм, заранее выбранный в формах создания УЦ и выпуска сертификата. См. [ГОСТ-алгоритмы](gost_algorithms.md). |
| Срок действия УЦ по умолчанию (дней) | `OWNCA_DEFAULT_CA_DAYS` | Подставляется в поле срока действия формы создания УЦ (по умолчанию `3650`). |
| Срок действия сертификата по умолчанию (дней) | `OWNCA_DEFAULT_CERT_DAYS` | Подставляется в формы выпуска и продления сертификата (по умолчанию `365`). |
| URL раздачи CRL | `OWNCA_CRL_DISTRIBUTION` | Только для сведения: при создании УЦ **не** подставляется, адрес CRL нужно указать в форме УЦ вручную. |

## Переменные окружения

Вторая таблица страницы перечисляет переменные окружения, влияющие на
работу панели, в том числе не показанные выше:

| Переменная | Назначение |
|---|---|
| `OWNCA_STORAGE_DIR` | Каталог файлов УЦ и сертификатов. |
| `OWNCA_OPENSSL_BIN` | Путь к программе `openssl` (gost-engine подключается через `OPENSSL_CONF`). |
| `OWNCA_DEFAULT_KEY_ALG` | Алгоритм ключа по умолчанию. |
| `OWNCA_DEFAULT_CA_DAYS` | Срок действия УЦ по умолчанию. |
| `OWNCA_DEFAULT_CERT_DAYS` | Срок действия сертификата по умолчанию. |
| `OWNCA_CRL_DISTRIBUTION` | Адрес, по которому публикуются CRL. |
| `OPENSSL_CONF` | Путь к файлу настроек OpenSSL, подключающему gost-engine. |

## Когда изменения вступают в силу

**Режимы выпуска** сохраняются в базе данных при нажатии
**Сохранить настройки** и действуют сразу, без перезапуска.

**Значения по умолчанию** и **переменные окружения** читаются только при
запуске. Чтобы их изменить, отредактируйте `dev_env/.env` (или
соответствующий файл в `demo/`) и перезапустите контейнер.
