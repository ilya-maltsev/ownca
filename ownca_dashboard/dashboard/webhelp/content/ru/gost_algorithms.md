# ГОСТ-алгоритмы

OwnCA может выпускать сертификаты с подписью по российским
криптографическим стандартам.

## Стандарты

| Стандарт | Назначение |
|---|---|
| **ГОСТ Р 34.10-2012** | Электронная подпись на эллиптических кривых. |
| **ГОСТ Р 34.11-2012** («Стрибог») | Хеш-функция с длиной значения 256 или 512 бит; используется при подписи. |
| **ГОСТ 28147-89**, **ГОСТ Р 34.12-2015** (Кузнечик, Магма) | Симметричное шифрование; используется при выгрузке в PKCS#12. |

Параметры сертификатов X.509, которые выпускает OwnCA:

| Параметр | 256 бит | 512 бит |
|---|---|---|
| OID алгоритма ключа | `1.2.643.7.1.1.1.1` | `1.2.643.7.1.1.1.2` |
| OID алгоритма подписи | `1.2.643.7.1.1.3.2` | `1.2.643.7.1.1.3.3` |
| Хеш-функция | ГОСТ Р 34.11-2012, 256 бит | ГОСТ Р 34.11-2012, 512 бит |
| Длина открытого ключа | 512 бит (две координаты по 256) | 1024 бита |

## Параметры эллиптических кривых

По умолчанию используется набор параметров **A**: для `gost2012_256` это
CryptoPro-A (`1.2.643.2.2.35.1`), для `gost2012_512` — paramSetA ТК 26
(`1.2.643.7.1.2.1.2.1`). Другой набор можно выбрать в форме: для 256 бит
доступны `A`, `B`, `C`, `XA`, `XB`, для 512 бит — `A`, `B`, `C`.

Рекомендуемые наборы параметров опубликованы на сайте
[ТК 26](https://tc26.ru/).

## Совместимость

* OpenSSL 1.1 и 3.x — с модулем gost-engine.
* CryptoPro CSP 4.0 и новее — принимает сертификаты и подписи OwnCA.
* nginx из комплекта поставки (OpenSSL с gost-engine) — TLS с наборами
  шифров `GOST2012-KUZNYECHIK-KUZNYECHIKOMAC` и `GOST2012-MAGMA-MAGMAOMAC`.

## Где выбирается в OwnCA

* На странице [Управление УЦ](cas.md) — алгоритм ключа УЦ.
* На странице [Выпуск сертификата](custom_cert_issue.md) — алгоритм ключа
  берётся из запроса, а если ключ создаётся на сервере, выбирается в форме
  (заранее выбран алгоритм по умолчанию).
* Алгоритм по умолчанию задаёт переменная окружения
  `OWNCA_DEFAULT_KEY_ALG` (см. [Конфигурация](configuration.md)).
