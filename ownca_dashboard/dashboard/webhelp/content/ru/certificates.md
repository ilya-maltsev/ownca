# Реестр сертификатов

Страница `/certificates/` (пункт меню **Сертификаты**) — список всех
выпущенных сертификатов. Отсюда открывается страница отдельного
сертификата, где его можно просмотреть, отозвать, продлить, удалить или
скачать.

## Отбор

Над таблицей два выпадающих списка:

* **УЦ** — показать сертификаты только одного УЦ;
* **Статус** — действующие, отозванные или просроченные.

Поиска по тексту нет.

## Столбцы

| Столбец | Содержимое |
|---|---|
| Общее имя (CN) | CN владельца; ссылка на страницу сертификата. |
| Издатель (УЦ) | Выпустивший УЦ; ссылка на его страницу. |
| Профиль | Название [профиля](cert_profiles.md) на момент выпуска; если профиль потом переименовали, здесь остаётся прежнее название. |
| Алгоритм | Алгоритм ключа. |
| Серийный номер | В шестнадцатеричном виде. |
| Действителен до | Дата окончания срока действия. |
| Статус | Действует, отозван или просрочен. |

Все действия с сертификатом выполняются на его странице — откройте её по
ссылке в столбце «Общее имя (CN)».

## Страница сертификата

На странице `/certificates/<uuid>/`:

* кнопки **Скачать сертификат**, **Скачать ключ** (если ключ хранится на
  сервере), **Скачать CSR**, **Скачать PEM-файл**, **Экспорт PKCS#12**,
  **Продлить**, **Отозвать**, **Удалить**;
* сведения о сертификате: владелец, статус, выпустивший УЦ, профиль,
  алгоритм, серийный номер, отпечаток SHA-256, срок действия, DNS-имена и
  IP-адреса из SAN, значения полей из реестра OID, где хранится закрытый
  ключ, сведения об отзыве и ссылка на исходный сертификат, если этот
  получен продлением;
* список **Продления, выпущенные из этого сертификата**, если они есть;
* полный текст сертификата (вывод `openssl x509 -text`) в блоке
  **Детали X.509**.

## Отзыв

Кнопка **Отозвать** открывает под собой форму с выбором причины:

| Причина | Когда указывать |
|---|---|
| `unspecified` | Причина не указана. |
| `keyCompromise` | Закрытый ключ скомпрометирован. |
| `CACompromise` | Скомпрометирован ключ УЦ. |
| `affiliationChanged` | Владелец перешёл в другую организацию. |
| `superseded` | Сертификат заменён новым. |
| `cessationOfOperation` | Сертификат больше не используется. |
| `certificateHold` | Временная приостановка. |

После подтверждения сертификат помечается отозванным, выпускается новый
CRL и делается запись в журнале выпусков CRL.

## Продление

Кнопка **Продлить** открывает форму с новым сроком действия. Тот же УЦ
подписывает исходный запрос (и использует тот же ключ, если он хранится
на сервере) с прежним профилем и значениями полей; меняются только срок
действия и серийный номер. Прежний сертификат остаётся действующим —
отзовите его, если он больше не нужен.

Файл исходного запроса должен сохраниться на диске, иначе продление
завершится ошибкой.

## Удаление

Кнопка **Удалить** удаляет запись из базы данных и файлы сертификата,
ключа и запроса с диска. Удалить можно сертификат в любом состоянии, в
том числе действующий. Удаление не вносит сертификат в CRL — для этого
его нужно отозвать.
