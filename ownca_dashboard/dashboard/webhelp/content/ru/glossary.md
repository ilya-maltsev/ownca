# Глоссарий

| Термин | Определение |
|---|---|
| **AIA** | Authority Information Access — расширение X.509 с адресом службы OCSP и адресом, по которому можно получить сертификат УЦ. |
| **ASN.1** | Abstract Syntax Notation One — язык описания структур данных, на котором определены сертификаты X.509 и связанные с ними объекты. |
| **CA, УЦ** | Certification Authority — удостоверяющий центр. |
| **CDP** | CRL Distribution Points — расширение X.509 с адресами, по которым публикуется CRL. |
| **CN** | Common Name — атрибут DN; обычно содержит имя владельца, адрес электронной почты или DNS-имя сервера. |
| **CRL** | Certificate Revocation List — подписанный УЦ список отозванных сертификатов. |
| **CSR** | Certificate Signing Request — запрос на сертификат (PKCS#10). |
| **DER** | Distinguished Encoding Rules — двоичная кодировка ASN.1; в ней сертификат подписывается и передаётся. |
| **DN** | Distinguished Name — отличительное имя: последовательность атрибутов (RDN), определяющих владельца или издателя. |
| **EKU** | Extended Key Usage — расширение X.509 со списком OID, определяющих назначение сертификата. |
| **Конечный сертификат** | Сертификат пользователя или сервера, а не УЦ. |
| **Issuer** | Издатель — УЦ, подписавший сертификат. |
| **Key Usage (KU)** | Расширение X.509 с набором битов, определяющих допустимые операции с ключом. |
| **OCSP** | Online Certificate Status Protocol — протокол проверки состояния сертификата в момент обращения. |
| **OID** | Object Identifier — уникальный идентификатор объекта; каждое расширение X.509 имеет свой OID. |
| **PEM** | Текстовое представление DER: данные в base64 между строками `-----BEGIN ...-----` и `-----END ...-----`. |
| **PKCS#7** | Формат, в котором можно передать один или несколько сертификатов. |
| **PKCS#10** | Формат запроса на сертификат. |
| **PKCS#12** | Защищённый паролем файл с сертификатом и закрытым ключом (`.p12`, `.pfx`). |
| **Проверка цепочки** | Проверка последовательности сертификатов вплоть до доверенного корневого УЦ. |
| **PKI** | Public Key Infrastructure — инфраструктура открытых ключей: УЦ, политики, программы и порядок выпуска сертификатов. |
| **Профиль** | В OwnCA — шаблон расширений сертификата. |
| **RDN** | Relative Distinguished Name — один атрибут DN. |
| **Корневой УЦ** | УЦ, сертификат которого подписан им самим; вершина цепочки. |
| **SAN** | Subject Alternative Name — расширение X.509 с дополнительными именами владельца: DNS, IP, адрес электронной почты, URI. |
| **Серийный номер** | Номер сертификата, уникальный в пределах УЦ. |
| **SIA** | Subject Information Access — расширение в сертификате УЦ с адресом хранилища сертификатов, выпущенных этим УЦ. |
| **SKI / AKI** | Subject Key Identifier / Authority Key Identifier — расширения с идентификатором, вычисленным по ключу владельца или УЦ. |
| **Subject** | Владелец сертификата. |
| **TSA** | Time-Stamping Authority — служба меток времени. |
| **VKO** | Алгоритм выработки общего ключа на основе ГОСТ Р 34.10-2012. |
| **X.509** | Стандарт МСЭ-Т на сертификаты открытых ключей. |
| **ГОСТ Р 34.10-2012** | Российский стандарт электронной подписи на эллиптических кривых. |
| **ГОСТ Р 34.11-2012 («Стрибог»)** | Российская хеш-функция с длиной значения 256 или 512 бит. |

См. также [Основные понятия](concepts.md) и [Устройство сертификата X.509](x509_overview.md).
