# Учётная запись администратора

В OwnCA одна учётная запись — администратор. Управлять пользователями в
панели нельзя: учётная запись создаётся автоматически по переменным
окружения.

## Имя и пароль

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DASHBOARD_ADMIN_USER` | `admin` | Имя пользователя. |
| `DASHBOARD_ADMIN_PASSWORD` | `admin` | Пароль. |

Значения по умолчанию годятся только для испытательного стенда. До первого
запуска задайте свои — в `dev_env/.env` или в переменных окружения
контейнера.

## Создание учётной записи

При каждом запуске контейнера:

1. если учётной записи администратора нет, она создаётся;
2. пароль устанавливается равным `DASHBOARD_ADMIN_PASSWORD`;
3. все прочие учётные записи без прав администратора удаляются.

## Смена пароля

Измените `DASHBOARD_ADMIN_PASSWORD` и перезапустите контейнер.

## Защита сеанса

Cookie сеанса передаётся с признаками `HttpOnly` и `SameSite=Strict` и
удаляется при закрытии браузера. Признак `Secure` ставится, если не задано
`DJANGO_SECURE_COOKIES=False`; в окружении `dev_env/` он выключен, чтобы
работал доступ по HTTP на порт 8001.
