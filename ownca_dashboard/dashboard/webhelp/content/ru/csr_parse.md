# Разбор запроса на сертификат

Разбор запроса — вспомогательная функция формы
[Выпуск сертификата](custom_cert_issue.md); отдельной страницы для неё нет.
Форма отправляет запрос по адресу `/certificates/csr-parse/` (доступен
только после входа) и получает в ответ его поля в формате JSON. По ним
форма заполняет сведения о владельце и SAN и показывает полный текст
запроса.

## Какие сведения извлекаются

Если какого-то атрибута в запросе нет, возвращается пустая строка или
пустой список.

| Поле | Описание |
|---|---|
| `common_name` | Атрибут CN из Subject DN. |
| `country` / `state` / `locality` / `organization` / `unit` | Остальные атрибуты Subject DN. |
| `public_key_algorithm` | Алгоритм открытого ключа, например `rsaEncryption`, `id-ecPublicKey`, `GOST R 34.10-2012`. |
| `key_alg` | Алгоритм ключа в обозначениях панели (`gost2012_256`, `rsa:2048`, `ec:P-256` и т. д.). Пустая строка, если длина ключа или кривая не входят в список алгоритмов панели. |
| `key_family` | Семейство ключа: `gost`, `rsa`, `ec` или `ed25519`. Определяется только по открытому ключу, алгоритм подписи запроса на него не влияет. Именно это значение сравнивается с ключом выпускающего УЦ. |
| `signature_algorithm` | Алгоритм, которым подписан сам запрос. |
| `paramset` / `paramset_raw` | Набор параметров ГОСТ (`A` / `B` / `C` / `XA` / `XB`) и его обозначение в том виде, в каком его вывел OpenSSL. |
| `san_dns` | DNS-имена из SAN. |
| `san_ip` | IP-адреса из SAN. |
| `requested_ku` | Биты Key Usage, указанные в запросе (только для сведения). |
| `requested_eku` | OID Extended Key Usage, указанные в запросе (только для сведения). |
| `raw_text` | Полный вывод `openssl req -text -noout`. |

Остальные типы SAN (адрес электронной почты, URI, otherName) не
извлекаются. Если они нужны в сертификате, введите их вручную в
соответствующие поля формы выпуска.

Принимается только запрос в формате PEM.

> **Важно.** Расширения, указанные в запросе, при подписании всегда
> отбрасываются. Результат разбора показывает, что *запрошено*, а не то,
> что попадёт в сертификат: расширения определяются выбранным профилем и
> полями формы выпуска.
